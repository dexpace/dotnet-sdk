# Appendix B map

Where each of the 61 items of the specification's conformance checklist
([`docs/product-spec/appendix-b-conformance-test-checklist.md`](../../docs/product-spec/appendix-b-conformance-test-checklist.md)) is evidenced in this
repository (phase 10, design P10-19). Two limits, before the table.

- **Appendix B covers nine of the nineteen requirement prefixes and is silent on `PAGE-4` and `PAGE-5`** (design §11 item 9). This map lists the IDs each item
  cites, 276 in all and none in two items, and states nothing about the 369 requirements the appendix never names; the appendix-C coverage script owns that count.
- **A `by reference` row proves a claim and a file, never the behaviour.** The gate checks that the file exists and that the IDs are the item's own; whether the
  tests in the file assert the clause is what the checklist rows of each phase argue (`docs/work/mvp/`). A `suite` row is stronger: it names an assertion of
  `Dexpace.Sdk.Conformance` that exists and cites one of the row's IDs, so a broken subject fails it (every assertion has a negative control).

**Columns.** `Section` and `Item` are the checklist's (`B.<section>.<n>`, the n-th bullet). `IDs` are the requirement IDs the item cites. `Evidence` is a
`; `-separated list: `<suite>:<assertion>` names an assertion of a kit suite (`transport`, `invariant`, `codec` or `packaging`; a trailing `*` matches a name prefix),
and anything else is a repository-relative path. `Status` is one of four, a row taking that of its least portable evidence: `suite` (an assertion of the kit),
`by reference` (a test file or gate in this repository that owns the item), `restated` (the design restates the item for .NET, named in Notes) and `scoped out`
(the port declines the whole item; none). `Notes` name every clause that is vacuous, declined or deferred inside an otherwise-evidenced item, with its citation, so a
row never reads better than its worst clause.

**Tally: 17 `suite`, 8 `restated`, 36 `by reference`, 0 `scoped out` (61).** The gate is
[`Requirements/AppendixBCoverageTests.cs`](Requirements/AppendixBCoverageTests.cs).
