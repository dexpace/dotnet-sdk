# Phase 1 — Security and Robustness Fixes: Checklist

The execution-time checklist for roadmap phase 1
([phase card](../2026-09-27-dotnet-sdk-v1-roadmap-design.md#phase-1--security-and-robustness-fixes-p0)): one row
per defect S1–S9, in the legend of the roadmap's cross-cutting constraint 3. Written from what was built on branch
`17-phase-1-security-core-fixes` (issue [#17](https://github.com/dexpace/dotnet-sdk/issues/17), S4–S8, core-only
unit tests) and completed on branch `18-phase-1-security-wire-fixes` (issue
[#18](https://github.com/dexpace/dotnet-sdk/issues/18), S1, S2, S3 and S9, whose proofs assert on the raw bytes the
loopback fixture received).

Each fix is the smallest change that closes the defect. A ✅ covers the clause named in the row, never the whole
ID: what the structural owner still has to build is the ⏳ in the same row, and that phase must keep the named
`Security` test green (constraint 5). Every proving test of S4–S8 failed against `6b416de`, and every proving test of
S1, S2, S3 and S9 against `cf56338`, before its fix, and passes after it; the pre-fix failure is quoted. A test
marked "pin" passed before the fix too: it holds a behaviour the fix must not break.

| Mark | Meaning |
|---|---|
| ✅ | Implemented and tested. The row names the test, the `[Trait]` category and the file. |
| 🚫 | Not built: a permanent simplification, with the reason and the design §10 topic or §11 resolution it rests on. |
| ⏳ | Deferred. The row names the plan task that will do it (phase, task number and path), or the `docs/first-release.md` entry that owns it. |
| N/A | Not applicable in this port. The row cites the design section that retires it. |

## Security advisory decision

No advisory is owed, and none is filed. Every defect S1–S9 was found in the unreleased `0.0.1-alpha.1` line: no
package has been published to NuGet or anywhere else (`PublicAPI.Shipped.txt` is empty, and `docs/first-release.md`
has no release), so no consumer can hold an affected version. The fixes are recorded in `CHANGELOG.md` under
`[Unreleased]` → `### Security`, with the breaking changes marked. `SECURITY.md`, the disclosure policy itself, does
not exist yet; it is issue [#19](https://github.com/dexpace/dotnet-sdk/issues/19)'s, and from the first published
version onward a defect of this class gets an advisory under it.
